# **App Name**: ParaConverter

## Core Features:

- Input File Selection: Enable users to select one or more input files from their local file system for conversion.
- Output Format Selection: Offer a range of output formats (e.g., PDF, JPEG, PNG) via a dropdown menu.
- Output Directory Specification: Allow users to specify a directory on their local system where the converted files will be saved.
- Parallel Conversion: Initiate file conversions using parallel processing to utilize multi-core processors efficiently.
- Conversion Progress Display: Provide visual feedback on the progress of each file being converted.
- Conversion Logging: Log each conversion

## Style Guidelines:

- Primary color: Deep purple (#673AB7) for a modern, sophisticated feel.
- Background color: Dark gray (#333333) to support the dark mode theme and reduce eye strain.
- Accent color: Bright lavender (#BB86FC) to highlight interactive elements.
- Body and headline font: 'Inter', a grotesque-style sans-serif, offering a modern and neutral aesthetic suitable for both headlines and body text.
- Use minimalist vector icons in lavender to represent file formats and conversion actions.
- Employ a modular layout with clear visual separation between sections for file selection, format options, and conversion controls.
- Implement subtle animations to indicate loading and conversion processes, enhancing the user experience without being distracting.
